## 问题分析
许愿瓶热点点不到的真实原因不是 z-index，而是**热点坐标系和图片对不上**：
- 容器是 `calc(100vh - 49px)` 全宽（约 814 × 671，比例 1.21）。
- 背景图 `scene.png` 是 1449 × 1086（比例 1.334），用 `object-contain` 后图被等比缩进，**上下出现留白**。
- 所有热点的 `left/top %` 都是相对外层容器算的，于是整体往下偏，瓶子那个透明 button 实际落在了空白区域 / 柜子下方某处，看起来"点不到"。

顺便：当还没集齐 5 片时，瓶子 button 的 `onClick` 是 no-op，点了也"没反应"。

## 改动

### `src/components/escape/Room3.tsx`

1. **新增内层 stage 容器**，固定 4:3 比例匹配 scene.png，居中放在外层容器里。所有热点（5 个物件 + 瓶子 + 门口发光按钮）都移到这个内层里，坐标 % 直接对应图片像素。
   - 外层：`relative w-full` + `height: calc(100vh - 49px)` + `flex items-center justify-center`
   - 内层：`relative h-full` + `style={{ aspectRatio: "1449 / 1086" }}`，背景图改成 `absolute inset-0 w-full h-full object-cover`（在内层里 cover 就等于完全贴合）

2. **校准瓶子坐标**（基于 1449×1086 实际像素估算）：
   - `BOTTLE_POS = { x: 74, y: 22, w: 7 }`，`aspectRatio: "1 / 1.6"`（覆盖瓶身+瓶颈即可）
   - 加 `z-20` 确保盖在背景上
   - 排查阶段临时给瓶子加一层非常淡的金边（`ring-1 ring-amber-300/30`），上线前可以删，但便于看是否对位
   - 等用户确认位置后再去掉调试边框

3. **瓶子在未集齐时也要有反馈**：点击时弹一个 toast/小 Modal 提示「还差 {n} 片碎片，先去桌上找找～」。

4. 同样道理，door 按钮和五个物件热点也都移进内层；它们原坐标本来就是按"图面比例"估的，迁到内层后会更准。
